# 🧠 AI Resume Analyzer (Resumind)

An AI-powered Resume Analyzer that evaluates resumes using ATS (Applicant Tracking System) principles and provides personalized feedback to help job seekers improve their chances of getting shortlisted.

## ✨ Features

- 📄 Upload resumes in PDF format
- 🤖 AI-powered resume analysis
- 📊 ATS compatibility score
- 📝 Detailed feedback on:
  - ATS optimization
  - Content quality
  - Resume structure
  - Tone & writing style
  - Skills section
- 🖼️ Automatic PDF-to-image conversion for preview
- ☁️ Cloud file storage
- 🔐 User authentication
- 📚 Resume history dashboard
- 📱 Fully responsive UI

```bash

```

```bash

```

## 🧠 How It Works

1. User logs in.
2. Uploads a resume (PDF).
3. Resume is uploaded to cloud storage.
4. PDF is converted into an image preview.
5. AI analyzes the resume against ATS standards.
6. Feedback and scores are stored.
7. User can view previous analyses from the dashboard.
